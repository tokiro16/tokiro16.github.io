今天把平板同时当成了副屏和手柄接收器。

电脑没有第二块屏，也没有蓝牙。手里正好有平板，就先拿它试了。

![桌面实拍：主屏、平板副屏和手柄](/covers/tablet-second-screen.jpg)

*图：主屏在跑博客，平板作为副屏，手柄通过平板的蓝牙回连电脑。*

## 需要的东西

- 一台 Windows 电脑
- 一台平板
- 一个蓝牙手柄
- [ParsecVDD](https://github.com/parsec-cloud/ParsecVDD)：虚拟显示器驱动
- [Sunshine](https://github.com/LizardByte/Sunshine)：串流主机端
- [Moonlight](https://moonlight-stream.org/)：串流客户端
- [MultiMonitorTool](https://www.nirsoft.net/utils/multi_monitor_tool.html)：窗口和显示器管理

思路很简单：先凭空造一块虚拟屏幕，让 Sunshine 只推这块屏，平板用 Moonlight 接住画面；手柄则通过平板的蓝牙连接，再由 Moonlight 把输入转发回电脑。

## 第一步：先造一块虚拟屏

安装 ParsecVDD 之后，在 Windows 的显示设置里添加一块虚拟显示器。

电脑本来没有第二块物理屏幕。不创建虚拟屏，Windows 就没有可以扩展的目标。ParsecVDD 的作用就是让系统以为这里真的有一块屏。

刚加出来的虚拟屏，分辨率可能不对，也可能被排在主屏左边或右边。先去显示设置里调到接近平板的分辨率，比如 1920 × 1200 或 2560 × 1600。

### 为什么还需要 MultiMonitorTool

虚拟屏没有真实的物理位置，有些窗口会开在看不见的地方，或者鼠标移过去就「消失」了。

MultiMonitorTool 可以列出当前所有显示器，并把指定窗口移动到某块屏幕上。我的做法是先把虚拟屏设为扩展屏，再用它把需要放到副屏的窗口挪过去。这样至少不会出现「程序启动了，但找不到窗口」的情况。

## 第二步：让 Sunshine 只推这块屏

打开 Sunshine，在 **Troubleshooting** 页面里找到显示设备的 `device_id`。虚拟屏和主屏都会出现在列表里，注意不要选错。

复制虚拟屏的 ID，回到 **Settings → Video**，把它填到显示设备相关的选项里。各版本选项名不太一样，反正就是让它只抓这块屏。

然后设置分辨率、帧率和码率。我一般这样设：

- 分辨率和平板保持一致，避免画面被拉伸。
- 帧率先设 60，够用再往上加。
- 码率从 20 Mbps 左右开始试，局域网稳定的话可以继续提高。

Sunshine 的 Web 管理界面记得设置密码。它是局域网工具，不要把端口直接暴露到公网。

## 第三步：让平板显示画面

在平板上安装 Moonlight，让它和电脑连在同一个局域网里。

添加主机时输入电脑的局域网 IP，Moonlight 会弹出一个 PIN。回到 Sunshine 的 PIN 页面输入这串数字，配对就完成了。

然后在 Moonlight 里选择刚才那块虚拟屏，设置好分辨率和码率，点开始。顺利的话，平板上的画面就是 Windows 的扩展桌面。

如果连上了但画面是主屏，大概率是 Sunshine 里的 `device_id` 没选对，或者虚拟屏没有被正确激活。

## 第四步：手柄反过来连电脑

手柄这部分是我最喜欢的。

电脑没有蓝牙，但平板有。把手柄通过蓝牙连接到平板，Moonlight 会把客户端的输入转发给主机，包括手柄输入。

于是链路变成了：

```text
手柄 → 平板蓝牙 → Moonlight → 局域网 → Sunshine → 电脑
```

电脑端会把收到的输入识别成手柄，游戏里该有的震动和按键映射也都在。平板既是副屏，也是无线手柄接收器，一举两得。

## 踩过的坑

1. **虚拟屏不出现**：装完驱动后重启一次，或者在显示设置里手动检测。
2. **窗口跑到屏幕外**：用 MultiMonitorTool 把窗口移回虚拟屏，别靠猜。
3. **Sunshine 抓到主屏**：重新确认 `device_id`，虚拟屏和主屏的 ID 很像，容易复制错。
4. **画面卡顿**：优先用有线网络连接电脑，平板尽量连 5 GHz；码率不要一上来就拉满。
5. **平板分辨率不匹配**：在 Windows 显示设置和 Moonlight 里都检查一遍，避免画面模糊或黑边。

## 实际体验

副屏主要用来放文档、聊天窗口和游戏攻略，主屏继续做正事。平板尺寸刚好，放在显示器下面不占太多桌面空间。

手柄的延迟在本地 Wi-Fi 下可以接受，玩动作游戏和模拟器没什么问题；音游或者对帧数极其敏感的竞技射击，还是老老实实插线更稳。

这套方案不一定适合所有人，也还谈不上完美。不过平板的屏幕和蓝牙现在都用上了，对我来说，这比再买一套硬件有意思。
